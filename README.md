## 🧑‍💻 About Me

I’m a passionate **Full Stack Developer** who loves turning clean code into powerful, scalable applications. I specialize in **Angular** on the frontend and **Node.js + Express** on the backend, with hands-on experience across **MySQL**, **SQL Server**, **MongoDB**, and **Redis**.

For the last **2.5+ years**, I've been working at **Naxtre Technologies Pvt. Ltd.** as a **Software Developer**, contributing to production-grade web apps.

🎓 I hold a **B.Tech** in Computer Science from  
**Gandhi Institute for Education and Technology, Khurda**, under **BPUT, Odisha**.

---

## 🚀 What I Do

- Build **SPA**s using Angular & TypeScript (standalone components, signals, zoneless change detection)
- Develop and maintain **REST APIs** with Node.js & Express — JWT auth, RBAC, Zod validation
- Work across **MySQL**, **SQL Server (SSMS)**, **MongoDB**, and **Redis** — including query tuning
- Integrate full-stack systems in real-world business applications
- Collaborate in Agile teams to deliver clean, scalable code
